# Test Case 3 — AI Cinematic

## Purpose

Validate prompt quality, generation planning, visual continuity, and scene sequencing.

## Scenario

Create a 60–90 second cinematic story intended primarily for AI video generation.

## Required Validation

- Reusable character descriptions
- Environment consistency
- Camera/style consistency
- Detailed scene prompts
- Logical generation sequence
- Continuity between shots
- Production-ready prompt package
