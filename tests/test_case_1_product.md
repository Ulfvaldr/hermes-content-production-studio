# Test Case 1 — Product / Influencer

## Purpose

Validate commercially useful short-form content planning.

## Scenario

Create a 60-second vertical promotional video for a consumer product.

## Required Validation

- Strong hook
- Clear target audience
- Product benefit presentation
- Vertical-video pacing
- Practical shot list
- B-roll or visual alternatives
- Suitable captions/on-screen text
- Clear call to action where appropriate
